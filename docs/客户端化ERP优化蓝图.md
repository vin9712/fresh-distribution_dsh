# 客户端化 ERP 优化蓝图

> 状态：需求澄清与技术评估稿（2026-08-26）  
> 目标：将现有 Web ERP 优化为面向文员高频操作、接近桌面客户端效率的生鲜配送 ERP。  
> 关联：`../01-design/DESIGN.md` 为权威业务设计；本蓝图用于沉淀已确认的体验目标、产品取舍与实施路线。涉及权威设计变更时，须回写并经确认。

---

## 1. 项目定位与边界

### 1.1 业务模式

- **模式**：单仓单点、JIT 生鲜配送；不建设库存驱动的仓配系统。
- **主要角色**：
  - 文员：维护客户、配送点和报价；录入订单、采购成本与验收单；打印待配送送货单并完成配送状态登记；
  - 老板：查看经营统计与对账。
- **主要设备**：PC 网页端；按客户单据格式使用 A4 或二联/三联针式打印机。
- **规模基线**：约 10 个客户、日均 20 张订单、单均 50 行、20 个配送点、2 名并发文员、约 110 个 SKU/报价量级。

### 1.2 首期不做

- 不做扫码枪、条码或移动端扫码验收；
- 不做路线规划、装车调度、复杂仓配与库存阻塞；
- 不做订单级采购成本分摊；
- 不做多终端离线协同，仅保障本机草稿不丢失。

## 2. 已确认的产品决策

| 决策 | 已确认规则 | 影响范围 |
|---|---|---|
| 录单方式 | 纯键盘优先，不建设扫码流 | 订单编辑器、快捷键、商品检索 |
| 录单目标 | 50 行订单应在 5 分钟内完成 | 页面性能、焦点流、批量输入 |
| 草稿保障 | 本机自动保存，刷新/网络抖动后可恢复 | 订单编辑、浏览器存储、异常提示 |
| 采购成本 | 按单次采购单批量录入，不强关联或拆分至销售订单 | 采购、经营报表 |
| 订单价格 | 下单时写入订单行快照；已确认未送货订单价格不随报价变化 | 报价、订单、验收、审计 |
| 报价周期 | 新报价面向新周期、新订单；历史和已下订单不回写 | 报价生效、订单取价 |
| 价格层级 | **取消配送点覆盖价与报价模板**，订单仅使用客户正式报价；未命中时由文员手工定价 | 价格查询、菜单、SQL、文档 |
| 缺价处理 | 未命中报价时允许文员手工填写单价；原因必填、无需主管复核 | 订单编辑、价格审计、确认校验 |
| 验收形态 | 保留独立验收单，文员在配送完成后录入实收 | 验收、订单状态、报表 |
| 送货合单 | 默认一配送点一张送货单；同时支持批量生成多个配送点独立单据，以及生成一张跨配送点合单 | 送货生成、模板、验收关联 |
| 工作台形态 | 可拖拽标签页、可调整尺寸的拆分面板、记忆个人布局 | 布局、标签页、订单录入页 |
| 打印 | 客户模板、多份输出、预印连续纸多联复写、针式精确套打；使用本地打印助手执行并返回打印结果 | 模板、打印链路、安全、部署 |
| 针式校准 | 首台验证设备为 Epson LQ-630K / LQ-630KII，纸张为预印连续纸多联复写；需以真实 Windows 驱动验证 JimuReport 是否支持稳定的逐打印机偏移校准 | JimuReport、打印机驱动、可选本地打印助手 |
| 采购入库 | 无库存意义；供应商到货后可进入“待确认成本”，成本最终确认后完成入库 | 采购状态、报表口径、页面文案 |
| 共享设备 | 同一 PC 的草稿、工作台布局与最近记录必须按登录用户隔离 | 本地存储、登录切换、隐私 |
| 布局持久化 | 用户的分屏尺寸、固定标签与排序长期保存，并可一键恢复默认 | 布局存储、标签页 |
| 布局同步 | 登录后跨 PC 同步个人布局、固定标签与未提交订单草稿；不要求同步列表列设置 | 用户偏好 API、草稿 API、冲突策略 |
| 草稿冲突 | 同一草稿在多台 PC 同时修改时，提示用户比较并选择版本；不得静默覆盖 | 草稿版本号、冲突界面、审计 |
| 报价发布 | 客户报价先以草稿编辑，统一发布后才对新订单生效 | 报价状态、取价、批量调价 |
| 待确认成本 | 可生成送货单、录入验收、进入销售日报；经营概览显示“成本待确认”且不计算毛利 | 采购状态、销售日报、经营报表 |
| 客户打印默认 | 客户可维护专属送货模板；默认每配送点一张 A4 单据，使用 HP 激光打印机 | 打印模板、送货生成、客户配置 |
| 跨点合单验收 | 跨配送点合单时，验收单仍按配送点分区录入实收与差异 | 送货明细、验收主从模型、报表 |
| 打印后改单 | 已打印送货单禁止直接修改订单；必须作废旧送货单后重开并重新打印 | 订单状态、送货单版本、审计 |
| 模板范围 | 客户专属模板仅覆盖送货单；报价单通过客户 Excel 格式导出，不进入送货打印体系 | 打印模板管理、报价、送货 |
| 打印拆分规则 | 默认按配送点生成；例外由送货单配置处理，可合并配送点或按最大行数拆分。明细按合并订单的业务顺序生成，允许仅对本次送货单调整打印顺序 | 送货生成、打印任务、模板渲染 |
| 拆单标识 | 拆分页使用同一送货单号，并显示“第 N/M 张”页码 | 送货单明细、模板数据 |
| 作废重开 | 旧送货单保留并标记作废；重开送货单必须使用新单号并关联原单 | 送货单状态、审计、打印 |
| 打印权限 | 文员在办公电脑上可打印全部待配送送货单；每次打印记录操作人和次数 | RBAC、送货列表、打印日志 |
| A4 输出 | HP 激光打印机，A4 纵向、单面 | 模板纸张设置、打印验证 |
| 针式纸张 | 三联、预印连续纸，参考尺寸约 241mm × 140mm；该值仅作纸张参考，模板可打印区域与驱动名称以实机测量为准 | 针式模板、实机验证 |
| 合单排序 | 以同一配送点下商品行数最多的订单作为基准，保持其行顺序；其余订单按下单顺序补充未出现商品 | 送货单生成、明细排序 |
| 合单行规则 | SKU、规格、单位与单价均相同才合并数量；任一不同则保留为独立行 | 送货单明细、金额、验收 |
| A4 分页 | HP A4 单据按标准页面高度自动分页，并保留重复表头与页码 | A4 模板、渲染数据 |
| 针式合单边界 | 跨配送点合单只允许 A4 输出；针式单据必须按单配送点拆分 | 送货生成、打印路径 |
| 针式分页 | 单配送点针式单据固定每页 10 条明细；跨页重复客户、配送点、配送日期与完整表头，并显示“第 N/M 张” | 针式模板、打印数据 |
| 送货单金额 | 针式与 A4 送货单均展示单价和金额；不同单价的相同 SKU 必须分行 | 模板字段、金额核对 |
| 跨点 A4 格式 | 按配送点分区展示、各区小计，在同一 A4 文档中连续分页 | A4 模板、送货明细 |
| 税额口径 | 当前不处理税额；送货单金额即业务结算金额 | 订单、送货、验收、报表 |
| 验收计价 | 实收数量变化时，沿用送货单快照单价自动重算验收金额 | 验收服务、金额快照、报表 |
| 验收异常 | 实收为零或实收大于送货数量时原因必填；短收建议填写但不强制；原因下拉含拒收、短收/缺货、临时加货、计量差异 | 验收页面、字典、审计 |
| 已确认改单 | 已确认且尚未打印送货单的订单，可撤回至草稿后完整修改并重新确认 | 订单状态、操作日志、送货生成 |
| 作废统计 | 报表默认只统计有效单；作废单与重开关联可供追溯查询 | 报表过滤、送货审计 |
| 撤回级联 | 撤回已确认订单时，自动作废其已生成但尚未打印的采购单和送货单 | 订单、采购、送货、审计 |
| 作废审计 | 打印后作废重开必须填写作废原因；在送货单列表筛选作废状态并查看重开关联 | 送货列表、作废原因、关联详情 |
| 共享单据撤回 | 未打印的共享采购单或送货单保留，自动扣除被撤回订单的商品并重算；不得影响其他订单 | 订单撤回、采购、送货、事务 |
| 确认后新增 | 确认后、打印前出现新增需求时，撤回原单至草稿修改并重新确认，不建独立补单 | 订单状态、送货生成 |
| 报价纠错 | 已发布报价不可撤回为草稿；错误报价需作废，再复制生成新报价单并修改后发布 | 报价状态、复制、审计 |
| 手工定价 | 手工定价仅保留审计记录，不自动生成补报价提醒或待办 | 订单行、操作日志 |
| 空关联单据 | 扣除撤回订单后若采购单或送货单无任何明细，自动作废并记录原因“订单撤回” | 采购、送货、作废审计 |
| 采购草稿编辑 | 订单汇总生成但尚未确认的采购单允许手工新增、删除、修改明细 | 采购编辑器、来源追溯 |
| 已确认采购纠错 | 已确认采购单允许直接修改数量或成本，并记录操作日志 | 采购服务、日志、经营口径 |
| 未打印送货编辑 | 已生成未打印送货单只能调整明细顺序、拆分和合并，不直接修改商品或数量 | 送货编辑、订单快照 |
| 报价复制期限 | 复制作废报价时默认带出原有效期，由文员确认或修改后发布 | 报价复制、有效期校验 |
| 采购修改报表 | 已确认采购单修改数量或成本后，立即重算受影响的历史经营周期 | 采购、经营概览、报表刷新 |
| 手工采购来源 | 无销售订单来源的采购明细标记“手工补货/无订单来源” | 采购明细、来源展示 |
| 送货调整版本 | 未打印送货单的排序、拆分、合并每次保存为可追溯的打印配置版本 | 送货配置、版本记录、审计 |
| 自动结构恢复 | 未打印送货单提供一键恢复系统自动生成结构 | 送货编辑、重算、用户体验 |
| 报价冲突 | 同客户、同商品的已发布报价有效期不得重叠；发布时提示冲突商品 | 报价发布、有效期校验 |
| 基础资料快照 | 客户与配送点资料在录单时写入订单快照；后续主数据修改不回写未确认或历史订单 | 订单快照、送货、审计 |
| 报价覆盖 | 每期报价应包含全部客户商品；可用当期价格为 0 表示该商品本期无有效价格 | 报价明细、录单缺价处理 |
| 零价报价 | 报价明细单价为 0 视为无报价；录单时必须手工填写单价并留下审计 | 取价、订单编辑、手工定价 |
| 验收纠错 | 已提交验收单发现错误，作废旧验收单后重新录入 | 验收状态、订单状态、审计 |
| 验收作废回退 | 作废已提交验收单后，关联订单回退至已送达，等待新验收单提交 | 验收状态机、订单状态 |
| 月结纠错 | 月结后禁止直接修改验收和采购成本；通过下月调整记录处理 | 月结、调整、报表 |
| 月结调整范围 | 下月调整记录可分别调整客户应收金额和采购成本，均需独立留痕 | 调整单、应收、采购成本、报表 |
| 经营概览周期 | 默认当天，可切换自然周、自然月和自定义日期范围 | 工作台、报表 |
| 当日统计口径 | 经营概览“当天”按配送日期统计 | 工作台、销售日报 |
| 报价切换空档 | 旧报价作废而新报价未发布时，允许手工定价并保留原因审计 | 录单、手工定价、报价切换 |
| 免费品规则 | 当前不存在赠品/免费品；0 元始终表示无报价，不得按 0 元下单 | 取价、订单校验 |
| 月结调整单 | 使用独立单号，支持草稿，由文员提交后生效，不引入审批 | 调整单状态、单号、审计 |
| 月结调整追溯 | 原订单显示调整摘要并链接对应下月调整单，不改写原订单快照 | 订单详情、调整单、报表 |
| 待验收日报 | 按配送日期显示待验收数量，但不计入销售金额 | 销售日报、工作台 |
| 送达登记 | 文员在办公电脑逐张手工标记送货单已送达 | 送货列表、订单状态、日志 |
| 验收超时 | 配送日期当天 11:30 后仍未验收的送货单在工作台标红提醒 | 工作台、待验收列表 |
| 对账默认周期 | 客户对账单默认自然月 | 对账单、日期筛选 |
| 月结粒度 | 按客户分别执行月结 | 月结操作、订单状态、客户对账 |
| 调整单报表生效 | 下月调整单提交后立即更新客户对账与经营概览 | 调整单、报表重算 |
| 提醒适用日 | 待验收标红提醒在所有自然日按配送日期当天 11:30 统一执行 | 工作台、定时检查 |
| 送达登记信息 | 文员标记已送达时系统自动记录当前时间，备注可选 | 送货单、操作日志 |
| 月结预览 | 月结前一键预览该客户本月验收单和调整单，并支持导出 Excel 线下核对 | 月结、对账单、Excel 导出 |
| 月结后对账 | 已月结客户当月对账单可查看和导出，不允许改动 | 对账单、月结锁定 |
| 经营结算态 | 经营概览区分已月结与未月结销售金额 | 经营概览、月结状态 |
| 报价草稿并发 | 使用乐观锁；保存/发布时比较版本号，冲突则提示用户刷新、对比后重试，不静默覆盖 | 报价编辑、版本号、并发控制 |
| 月结 Excel | 同时支持系统统一格式与客户专属格式导出 | 月结导出、Excel 模板管理 |
| Excel 模板维护 | 客户专属月结/报价 Excel 模板由文员在模板管理中设计和维护 | Excel 模板、权限、导出 |
| 待验收提醒 | 送货单打印满 2 小时仍未验收显示黄色；配送日当天 11:30 后升级红色；同时显示在工作台卡片和送货单列表行 | 工作台、送货列表、提醒计算 |
| 打印设备资料 | Epson 与 HP 的具体驱动、纸张实测尺寸和可打印区域待现场确认 | 针式/A4 技术验证 |
| 打印模板权限 | 文员与管理员均可直接设计、修改打印模板 | 模板管理、RBAC、审计 |
| 打印模板发布 | 模板采用草稿→预览测试→发布；已发布版本在新版本发布前继续使用 | 模板状态、版本、打印选择 |
| 报价冲突处理 | 乐观锁冲突时逐行展示本地值与服务器值，由文员选择保留值后重新提交 | 报价差异对比、合并、版本号 |
| 模板回滚 | 可选择任一历史发布版重新发布；回滚生成新版本，不覆盖历史版本 | 模板版本、回滚、审计 |
| 模板版本说明 | 不强制填写版本说明；系统自动生成版本号并记录修改人、时间和来源版本 | 模板版本、操作日志 |
| 模板绑定优先级 | 客户+配送点组合 → 客户 → 全局默认 | 模板匹配、送货打印 |
| 正式打印预览 | 每次正式打印送货单前必须预览，确认后才能创建打印任务 | 打印流程、状态、审计 |
| 预览临时调整 | 预览页可切换已发布模板、选择打印机、调整本次份数；不可临时调整页边距/偏移 | 打印预览、打印任务 |

## 3. 客户端化体验标准

### 3.1 文员录单工作台

订单编辑页应成为最高优先级的桌面工作区：

1. 左侧为订单头与可编辑明细表；右侧为可切换的常用商品、最近订单与商品搜索面板；
2. 左右区域可拖拽调整宽度，最小宽度受控；用户设置在本机记忆；
3. 商品选择、数量、单价、下一行形成稳定键盘焦点流；
4. 提供复制行、插入空行、删除行、批量粘贴、重复上一行、撤销最近编辑等高频操作；
5. 客户、配送点、配送日期发生变化时，明确提示会影响商品池和取价；
6. 草稿自动保存、恢复、清理和提交成功后的删除均可见、可解释；
7. 无需扫码功能，不因扫码逻辑干扰键盘录入与验收页面。

手工定价不是绕过报价的无痕操作。订单行应保存“报价来源=手工”、原建议价（如有）、手工单价、必填原因、操作者和时间；确认订单时提示并写入操作日志，但不引入主管复核流程。

### 3.2 多任务与信息密度

- 标签页支持固定、拖动排序、关闭其他、恢复上次工作现场；
- 高频页面优先支持可拆分面板，避免文员在订单、客户、报价和历史单据间反复跳转；
- 弹窗仅用于短任务；大任务采用抽屉或可保留上下文的工作区；
- 统一空态、加载态、错误态与权限不足反馈，避免无结果掩盖越权或请求异常。

### 4.2 依赖和架构结论

- 当前 Vue 3、Element Plus、vxe-table 已足够支撑桌面化 Web 工作台，**不应为“像客户端”而立即重写为 Electron**；
- 若需本地打印能力，优先将其限定为可选“打印助手”边界，业务系统仍维持浏览器部署；
- 当前体量不要求引入复杂离线同步或微服务；应先完成页面状态、键盘交互与打印稳定性；
- Pinia 虽已安装，但当前项目已有既有状态管理方式。实施新能力前需统一状态边界，避免同一业务同时使用多套全局状态方案。

## 6. 打印目标架构

> **范围收敛（2026-08-26）**：本节记录的是长期能力边界，不代表首期全部实施。当前打印交互与最小状态以同目录《打印模板交互与整体流程》为准，实施与验收顺序以《打印模板分阶段实施计划》为准。首期先修复现有 JimuReport 打印闭环并完成 Epson/HP 实机验证；本地助手、复杂任务队列、模板导入导出和长期归档均按验证结果后置。

```mermaid
flowchart LR
    A[送货单业务数据] --> B[模板选择：客户或全局默认]
    B --> C[JimuReport 模板与预览]
    C --> D{打印类型}
    D -->|A4/普通格式| E[浏览器打印]
    D -->|针式连续纸/精确套打| F[本地打印助手]
    E --> G[打印审计]
    F --> G
    G --> H[打印次数、操作者、时间、模板版本]
```

关键约束：

1. 模板绑定、份数、单据数据、打印日志由业务后端统一管理；
2. 本地打印助手只接受短时、一次性的打印任务，不直接暴露数据库或长期登录凭据，并返回任务成功/失败回执；
3. 每个打印任务记录模板版本、目标打印机、份数、操作者和结果；
4. JimuReport 负责模板设计与预览；首台验证为 Epson LQ-630K / LQ-630KII + 预印连续纸多联复写。针式打印必须先验收“实际纸张尺寸、偏移校准、多联一次走纸、断纸/缺纸失败反馈”。浏览器打印配置通常无法稳定按打印机保存精确偏移，因此是否需要本地助手以实机结果为准。
5. 模板决定呈现格式和纸张类型；送货单配置决定业务数据如何合并或按行数拆分；打印任务决定实际目标打印机、份数与执行结果。三者必须分离，不能用模板配置替代送货生成或拆分规则。
6. 送货单同时支持两条输出路径：针式预印多联连续纸（Epson）与 A4 激光打印（HP）。报价单不复用该打印链路，应输出客户所需 Excel 格式后由业务自行打印或发送。
7. 合并订单时，以商品行数最多的订单为基准保留其行顺序；其余订单中未出现商品按下单顺序追加。SKU、规格、单位和单价均相同时才合并数量，避免不同价格混在同一行。
8. 针式单据仅打印单配送点，固定每页 10 条；跨配送点合单仅输出 A4，按配送点分区并输出小计。两种格式均展示单价和金额。
9. 系统不处理税额；验收金额按送货单快照单价 × 实收数量重算。实收为零或超送时必须填写原因，短收建议填写；原因下拉包含拒收、短收/缺货、临时加货、计量差异。
10. 打印模板与物理打印机严格解耦。模板只声明所需介质和版式，本地助手将逻辑介质映射到 Windows 物理打印机；更换打印机时模板无需修改，只需重建映射并测试。

### 6.1 本地打印助手是什么

本地打印助手不是 hiprint 一类的模板设计器，也不替代 JimuReport。三者职责不同：

| 组件 | 职责 |
|---|---|
| JimuReport | 在网页中设计模板、绑定字段、预览版式并生成待打印内容 |
| 本地打印助手 | 安装在 Windows 文员电脑上的托盘程序；接收网页签发的短时打印任务，选择指定打印机/纸张，调用 Windows 打印队列，应用偏移校准并返回成功或失败 |
| hiprint | 前端模板设计与渲染方案；本项目已决定以 JimuReport 为主，因此不作为本地助手本身 |

本地助手可以理解为“网页 ERP 与 Windows 打印机之间的受控桥梁”，不提供业务数据编辑能力。本项目优先采用助手主动连接后端、拉取已签名任务的方式，避免网页直连 `localhost` 带来的 HTTPS、CORS、本地证书和端口问题。首选先验证成熟打印服务是否满足需求；只有无法满足 Epson 精确套打、任务回执和偏移配置时，才开发轻量自有助手。具体架构和 H0～H4 验证步骤见《本地打印助手技术方案与验证计划》。

## 7. 报表口径与数据边界

### 7.1 首期报表

- 销售日报：以验收为事实，统计实收金额、损耗、客户与配送点；
- 客户对账单：按客户和结算周期列出验收单及明细；
- 经营概览：展示周期销售额、采购额、损耗额与**周期经营毛利/估算毛利**。

### 7.2 必须避免的误导

采购成本不拆分至销售订单时，不应在单张销售订单上展示“精确采购毛利”。若展示毛利，必须标注其计算范围与口径，例如：

$$
\text{周期估算毛利} = \text{验收实收金额} - \text{同周期采购金额}
$$

该指标适用于经营观察，不等同于逐订单、逐客户或逐 SKU 的精确成本核算。

### S0：设计与安全基线

7. 改造打印鉴权为短时、一次性票据；
8. 建立快捷键冲突表与页面级验收清单。
9. 验收原因维护为字典或受控配置，至少覆盖拒收、短收、临时加货、计量差异。
10. 为已确认采购单的直接修改补充操作日志、修改前后金额记录和报表重算测试。
11. 为送货单打印配置实现版本记录与“恢复自动生成结构”，并增加重叠报价发布校验。
12. 订单、客户与配送点相关查询使用订单快照字段，避免主数据变更影响未确认和历史单据。
13. 新增下月调整单（草稿/已提交、独立单号、应收与采购成本调整字段），并在原订单中提供关联摘要。
14. 工作台按配送日期检查待验收单，超过当天 11:30 标红；实现按客户月结与调整单提交后报表即时重算。
15. 月结页面支持验收单/调整单预览与 Excel 导出；月结后冻结对账数据，并在经营概览区分结算状态。
16. 客户报价草稿使用服务端版本号乐观锁；月结导出支持统一模板与客户模板；将打印机资料采集列入现场验证清单。
17. 打印模板增加草稿、预览测试、发布状态和版本；待验收提醒按“打印后 2 小时黄色、当天 11:30 后红色”计算。
18. 报价冲突提供逐行差异选择；打印模板支持历史版本重新发布、三级绑定和每次打印前强制预览。
19. 预览页支持模板、打印机和份数的本次调整；本地打印助手提供可靠回执，成功次数与失败任务分开统计。
20. 单张强制预览、批量汇总预览；助手不可用时禁止打印；重试建立关联任务，批量失败时立即停止队列。
21. 批量预览允许逐单调整；打印助手采用“服务端逻辑配置 + PC 设备映射/偏移”，开机托盘常驻并由文员确认升级。
22. 文员可维护设备映射；偏移按打印机型号+纸张规格保存；测试打印使用真实单据加水印且不计正式次数；助手升级不得中断任务。
23. 先验证成熟打印服务再决定自研；模板发布设置自动校验与测试打印双门禁，校准配置可安全迁移。
24. 模板始终显示页码，签收区可选；发布人自测确认，系统以长文本边界数据阻止溢出，针式优先使用客户短名称。
25. 无短名称时允许截断但必须预警；短名称+规格在客户内唯一；模板测试加整页水印，客户模板只从全局模板复制，停用后自动降级匹配。
26. 客户模板复制后独立；已绑定模板须先配置替代版本才能停用；正式使用过的版本不可删除，历史重打固定使用首次模板版本。
27. 替代模板可跨介质但须重测；历史重打可换同介质设备；新模板立即作用于新任务，每个绑定维度仅保留一个活动草稿。
28. 模板草稿使用乐观锁；过期预览不能打印；队列任务固定创建时版本；模板仅使用受控字段，并允许固定文字与 Logo。
29. Logo 全局统一；固定文字样式受控；模板字段按弃用迁移流程治理；模板可安全导入导出但必须脱敏并重测。
30. 正式任务固化 Logo 快照；字体缺失回退微软雅黑并提示；不兼容模板禁止导入；打印任务保留 5 年，正式模板版本永久保留。
31. 未使用模板由文员手工清理；五年打印任务先归档后清理；字体回退必须重览；份数来自模板，打印机按介质映射和上次使用自动选择。
32. 模板不绑定物理打印机；换机只更新设备映射。归档采用数据库包+CSV 索引，设备首次用配对码绑定，打印任务使用短时签名。
33. 同型号设备可复用映射，不同型号须重校准；设备映射保留完整诊断元数据，A4 换机需测试，驱动变化会冻结映射待复验。
34. 模板坐标统一使用毫米；逻辑边距与设备偏移分层；助手提供校准测试页；纸张规格集中管理而非每个模板重复录入。
35. 新纸张规格立即可用于设计，但已引用尺寸不可变；偏移限制 ±20mm；正式打印固定 100%；预印扫描图仅作设计参考。
36. 预印底图限 PNG/JPG 5MB，按模板版本固化；导出默认携带但可排除；纸张复制不自动继承校准值。
37. 模板文件保持开放 JSON/压缩包，但导入必须安全校验；图片使用本机文件目录并与数据库同批备份，历史引用资源不可物理删除。
38. 外部模板导入采用全有或全无校验，禁止网络资源；导入后为重命名的未绑定草稿，须重走完整发布门禁。
39. 模板导出可选历史版本，导入包限制 20MB 且来源元数据不替代本地审计；模板列表提供业务筛选，设计草稿自动保存并使用乐观锁。
