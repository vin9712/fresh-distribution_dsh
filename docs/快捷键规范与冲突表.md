# 快捷键规范与冲突表（W0-5.2）

> 依据：`客户端化ERP优化蓝图.md` §3.3、《客户端化ERP改善计划.md》 0.5.2。
> 本文档是**后续页面接入快捷键的准入检查清单**：新页面/组件注册快捷键前必须先核对 §3 冲突表，禁止再出现 `window.addEventListener('keydown')` 散落监听。

## 1. 规范

### 1.1 集中注册

- 所有快捷键一律经 `RuoYi-Vue3/src/utils/shortcut.js` 的 `registerShortcut()` / `registerShortcuts()` 注册，全局唯一 `window keydown` 监听统一分发；
- 组合式 API 页面用 `src/composables/useShortcuts.js`（自动处理注册/注销/keep-alive 启停）；
- 选项式组件（如 QuickTable）在 `mounted` 注册并在 `beforeUnmount` 调用返回的注销函数。

### 1.2 作用域与优先级

| 作用域 | SCOPE 常量 | 典型绑定者 | 示例 |
|---|---|---|---|
| 全局 | `SCOPE.GLOBAL` | 布局层、全局搜索 | `Ctrl+K` 打开全局搜索、`Esc` 关弹窗/退全屏 |
| 工作区 | `SCOPE.WORKSPACE` | 页面/工作台（路由级） | 订单工作台 `F2` 切换右面板 |
| 表格编辑 | `SCOPE.TABLE` | 表格组件（QuickTable、未来订单明细表） | `F2` 新增、`Ctrl+S` 保存 |

- 同一键在多个作用域注册时，按 **全局 > 工作区 > 表格** 顺序分发；
- 分发为**责任链**：handler 返回 `false` 表示「不处理，继续下传」；返回其余值即视为已处理（自动 `preventDefault + stopPropagation`）；
- 同作用域同键重复注册：开发环境 console.warn 提示（`findShortcutConflicts()` 可程序化核对）。

### 1.3 硬性保护

1. **中文输入法组合态**：`event.isComposing === true` 或 `keyCode === 229` 时一律不分发（蓝图「不在中文输入组合态触发」）；
2. **输入焦点保护**：目标为 `input / textarea / select / contenteditable` 时默认不分发；例外：
   - 带 `ctrl` / `meta` 修饰键的组合（如 `Ctrl+S`、`Ctrl+K`，录入惯例）；
   - 绑定显式声明 `allowInInput: true`（如 `Esc` 关闭弹窗）；
3. **keep-alive 页面**：失活工作区的绑定自动停用（`useShortcuts` 内 `onActivated/onDeactivated` 启停），保证「仅由当前活动工作区响应」。

### 1.4 推荐键位（蓝图 §3.3）

| 范围 | 键位 | 含义 |
|---|---|---|
| 全局 | `Ctrl+K` | 全局搜索 |
| 页面 | `F2` / `F3` / `Delete` / `Esc` | 新增 / 聚焦搜索 / 删除 / 清除或关闭 |
| 表格 | `Enter` / `Tab` / `Ctrl+S` | 焦点流转 / 行级校验保存 |
| 标签页 | `Ctrl+W`（建议） | 关闭当前可关闭标签（未实施，见 §4） |

## 3. 冲突表（历史冲突与处置）

| # | 冲突 | 服务化前行为 | 处置 |
|---|---|---|---|
| C1 | `Esc`：GlobalSearch 关弹窗 vs QuickTable 清空选择 | 两个 window 监听同时触发：关弹窗的同时清掉了表格选中态 | GlobalSearch 绑定 global 作用域先分发；QuickTable 无选中返回 `false` 下传、有选中时在弹窗打开前被 global 拦截 |
| C2 | `Ctrl+K`：GlobalSearch 直开 vs QuickTable emit global-search | 双重处理（重复调用 open） | QuickTable 的 `Ctrl+K` 移除，统一由 GlobalSearch global 绑定承担 |
| C3 | `F2`/`F3`：QuickTable 在判断输入焦点**之前**匹配 | 搜索框输入时按 F2 误触「新增」 | 服务层输入焦点保护统一前置；QuickTable 页面 F2/F3 不再在输入框内触发 |
| C4 | keep-alive 缓存页失活后监听仍生效 | 已离开页面的快捷键仍被触发 | `useShortcuts` 自动启停；选项式组件随 `beforeUnmount` 注销 |
| C5 | 未来风险：新页面直接 `window.addEventListener('keydown')` | 无法感知已有绑定 | 准入检查（§4）+ 开发环境重复注册告警 |
| C6 | `Esc`：TagsView 退出标签区全屏 vs GlobalSearch 关弹窗（同为 global） | — | **有意责任链，非冲突**：TagsView 先注册（非全屏返回 `false` 下传）→ GlobalSearch 后注册（弹窗未打开返回 `false`）。两边 `chain: true` 标记后告警豁免（shortcut.js：`chain` 为意图链式标记，`registerShortcut` 同作用域同键任一方声明 `chain` 则不告警） |

## 4. 准入检查（新页面/组件接入快捷键前逐项核对）

1. ☐ 是否已核对 §2 现状注册表，不新增同作用域同键绑定？如确需覆盖，低优先级 handler 是否按「返回 false 下传」实现？
2. ☐ 是否使用 `useShortcuts`（组合式）或 `registerShortcuts`（选项式）？**禁止**直接 `window.addEventListener('keydown')`；
3. ☐ 页面级绑定作用域是否为 `SCOPE.WORKSPACE`？表格组件是否为 `SCOPE.TABLE`？仅布局级行为可用 `SCOPE.GLOBAL`；
4. ☐ handler 是否幂等且轻量（不做网络请求的隐式触发）？需要防抖的高频键是否已处理？
5. ☐ 是否填写了 `owner`（组件/页面名）与中文 `description`（供 `getShortcutRegistry()` 生成注册表）？
6. ☐ 是否在本文档 §2 表格补一行登记？
7. ☐ 中文输入法下逐键验证：输入拼音组合态期间按键不触发任何快捷键；
8. ☐ keep-alive 缓存路由验证：切换标签后原页面快捷键不再响应，返回后恢复。

## 5. 已知未实施项

- 订单明细表（S1）的 `Enter`/`Tab` 焦点流：待 S1 拆分 `detail.vue` 时以 `SCOPE.TABLE` 接入；
- `getShortcutRegistry()` 目前为手工导出，后续可挂开发调试页自动生成 §2 表格。
