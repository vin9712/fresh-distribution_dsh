# 文员快速上手指南

> **适用对象**：文员 / 录单员
> **系统入口**：http://localhost:1025（开发环境）
> **配套文档**：完整功能细节见 [操作手册.md](./操作手册.md)，本指南只讲"每天要干什么、怎么干"
>
> ⚠ **v1.5（2026-09-04）重改「送货单 = 订单的视图」（D-055）**：
> 不再有「生成送货单 / 待生成清单 / 补单 / 作废重建 / 打印包 / 组单策略」这套动作——
> **订单录完保存，送货数据就存在了**。每天的入口改为
> **「单据管理 → 客户日总表」**（一个页面切三口径：矩阵总表 / 配货总表 / 点单），
> 在该页直接**打印总单或点单**、点**生成验收单**。旧「送货单据」页只用于查 D-055 前的历史单。

## 一、文员的职责一句话

**把客户的订单录对，把货验收实，把客户资料和报价维护好。**

日常 80% 的时间花在两个页面：**销售订单** 和 **验收单**；其余是周期性的 **新客录入** 和 **报价维护**。

## 三、每日工作清单（建议顺序）

### ① 开工：看工作台
打开首页「工作台」，卡片就是今天的活：
- **待录/待确认订单** → 去订单页录
- **待生成采购单** → 提醒业务/主管确认
- **待验收** → **直接指回验收单页**（也可从客户日总表点单口径点「生成验收单」）
- **待处理加退换** → 核对退货单

> `[v1.5]` 原「待打印送货单」卡与顶部「送货单生成异常」告警条已随 D-055 下线（不再生成单据，也就没有生成失败）。

### ② 订单核对（录单）
在「销售订单」里逐单检查：
- 左侧明细表：**名称、单位、数量、单价、金额** 是否正确
- 右侧面板用「常用 / 最近」快速挑商品，不用翻全部商品
- 录单时改了价会有提醒，确认是有意为之再保存

录完之后（**v1.5 新流程，不再“出单”**）：
- 订单**保存并确认后，送货数据已存在**——去「单据管理 → **客户日总表**」选客户+配送日期即可看到：
  - **矩阵总表**：行=菜品、列=该客户各配送点、格=应送数 → 点「打印总单」（司机对单，标题 `<客户>总单`）
  - **配货总表**：不拆价的汇总 → 给工人采购/配货，用浏览器「打印本页」
  - **点单**：选配送点 → 看该点明细（订单号/应送/实收/加换退标记）→ 点「打印点单」（客户签收，验收数留空由送货员手填）
- **配送前改单 = 直接改订单**（无标记）；改完刷新日总表就是新数据
- **配送后（已打印）改单 = 订单列表行上点「配送后变更」**：加单 / 换货 / 退货，原行不动，以标记追加（点单区会显示“已打印/未打印”提示当前处于哪个阶段）
- 现场多加（实收 > 应送）属正常，不打标记，验收时直接录实收
- 已打印后**仍允许直接改订单**（现行口径），但推荐走带标记的变更以保留现场痕迹；**验收提交后订单冻结**（需先撤销验收）

录单页几条固定规矩：
- **送货单位在录入商品后即整体锁定**（含客户），要换必须点表头的「重开新单」，不允许半途只换单头；**还没录商品时可直接改选**配送点（明细自动清空重取价）；未选送货单位前不能录商品行
- **订单编号只能系统生成**：进入页面看到的是预览号，点刷新图标会跳过已被占用的号，保存成功那一刻才真正占号
- **草稿自动保存双保险**：录入中自动存草稿（本地+服务器），误关网页后回到录单页可按横幅提示恢复；保存成功后草稿自动清除
- **点「最近」里的单子：空工作区直接改，正在录单则只读看**（`[2026-08-29]` 调整）
  - 当前**没在做新单**（送货单位未选 / 没有有效商品行）→ 点行即以**编辑模式**打开该草稿单，顶部挂「正在编辑已有草稿订单，点错了？← 返回重开新单」横幅，改完直接保存
  - 当前**正在录新单** → 弹窗确认后收起工作区，进**只读浏览**（顶部「← 返回我的新单」随时切回，数据不丢）
- **复制为新单**（底部「重置 / 保存」旁）：只要当前打开着一张**已保存**的单（含已验收/已结算的只读历史单），点它就以它为模板另录一张——**商品与数量整单带过来，单价按当前执行价重取**，配送日期重算（15 点前=今天、之后=明天）；会丢弃未保存改动或已收起的工作区时先弹二次确认

### ③ 验收（应收 vs 实收）——在验收单页完成
核心原则：**下单数量不改，以实际收到为准；实收归属到配送点。**

**进入验收：**
1. 订单变为「已配送」后，订单列表点 **「去验收」**：系统自动定位该订单所在送货单的验收单（已有则打开，没有则建草稿直接进录入），该订单贡献的行会**黄色高亮**
2. 也可直接去「单据管理 → 验收单」筛已送达未验收的送货单

**填实收：**
3. 明细按**商品分组**展示：组头是应送/实收/差异合计（只读），在**各配送点行**上填实收（默认 = 应送，只改有差异的行）；跨点总单会自动展开成「配送点×商品」的行，**录入即归属到该点**，系统不会自动在点间分摊
4. 每行都有**来源对照列**（来源订单号/分配量×单价），下单 vs 应送 vs 实收在同一屏对照
5. **双向差异原因必填**：实收少于应送（短收）选短收原因（缺货/拒收/损耗/质量问题/错送/其他）；实收多于应送（超收）选超收原因（临时加送/计量差异/录单遗漏/其他）；差异改回零则原因自动清空
6. 核对无误点 **「提交验收」**；来源订单变为「已验收」，实收金额同步回订单页（只读镜像）

仓库现场可开**移动模式**（扫码枪连续扫码定位商品、大卡片翻页），仅改布局不改数据。

**填错了怎么办？**
- 在**验收单页**对已提交的验收单点 **「撤销验收」**：原因必填，系统留存撤销前完整快照；验收单回草稿、订单退回「已配送」重新验收
- 注意：**任一来源订单已月结则不能撤销**；月结后只能下期冲销或走退货单

### ④ 收尾：清理临时商品
录单时来不及建正式商品的，会以**临时商品**存在。每天收尾去「基础信息 → 别名与映射」：
- 能对应到标准商品的 → 点「转正」，关联到正式 SKU
- 确实是一次性的 → 保留或删除

## 四、新客入职 SOP（一次性，约 15 分钟）

```
第1步 建客户        →  第2步 导客户商品      →  第3步 报执行价
客户信息             客户商品                  商品报价
└ 客户 + 配送点      └ 快速同步粘贴报价单      └ 从客户商品池组装报价明细
```

1. **建客户**：「基础信息 → 客户信息 → 新增」，填名称、联系方式等；
   然后在客户的「**配送点**」里添加收货点（一个客户可以有多个配送点）。
   > `[v1.5]` 原「送货单组单策略 / 相同商品合并」两字段已随 D-055 下线（不再生成单据，矩阵/配货/点单均按订单明细实时取数），客户页不再展示与填写。
2. **批量导客户商品**：「基础信息 → 客户商品」→ 打开「**客户商品快速同步**」弹窗：
   - 选客户，文本框里粘贴报价清单，**每行一条**，两种写法都行：
     ```
     土豆=黄心土豆     ← 客户叫法=系统内部商品名
     西红柿            ← 直接写内部商品名
     PG                ← 助记码也可以
     ```
   - 系统按名称/助记码自动匹配标准 SKU；没匹配上的行列出来，不影响其它行
   - 建议勾上「**转临时**」：没匹配到的自动存为该客户临时商品，之后按每日清单第④步转正
3. **生成报价**：「基础信息 → 商品报价」新建报价单，从该客户商品池组装明细、填执行价。
   - **频率**：只在签新客或调价周期（一般 **1–2 周**）做一次，不是每天

## 五、关键概念速查

| 概念 | 一句话解释 |
|---|---|
| SPU / SKU | SPU=标准商品（如"土豆"），SKU=具体规格（如"黄心土豆 10斤/箱"），编码 S+8位 |
| 客户商品池 | 这个客户能订哪些商品，以及他自己的叫法、起订量 |
| 临时商品 | 录单时现编的品，先用起来，之后转正 |
| 转正 | 把临时商品挂到正式 SKU 上，历史单据跟着更新 |
| 应收 / 实收 | 应收=订单数量（日总表上的应送）；实收=实际收到的数量（**在验收单页填写**，提交后回写订单行镜像） |
| 总单 / 点单 | 同一份订单数据的两种**打印形态**：总单=客户当日矩阵（司机对单），点单=客户+日期+配送点（客户签收）；不再是两张单证 |
| 配送后变更 | 已打印后的现场调整，以标记追加在订单明细上：加单 / 换货（被换行标退货+换入行标换货）/ 退货（原行应送实收归 0） |
| 执行价 | 客户实际结算的单价，来自报价单 |

**取价规则**（录单时系统自动找价）：仅使用客户正式报价；未命中（含单价为 0）返回空价，人工定价。
> `[2026-08]` 原报价模板层已随价格层级简化下线，全系统仅一种取价口径。

## 六、常见问题 FAQ

**Q：客户报的菜名系统里搜不到？**
先试助记码/简称；实在没有就录成临时商品，当天收尾时转正或让管理员补标准商品。

**Q：当天菜录错了（数量/价格/漏行）怎么办？**
未打印：直接改订单保存即可（日总表/点单实时刷新）。已打印：用订单列表行上的**「配送后变更」**做加单/换货/退货（带标记保留现场痕迹）；不要为了凑数乱填实收。

**Q：还要“生成送货单”吗？**
不需要。`[v1.5]` 送货单已改为订单的视图，录完保存即存在；去「客户日总表」选客户+日期直接看与打印。

**Q：验收后发现实收填错了怎么办？**
在**验收单页**对该验收单点「撤销验收」（原因必填），回草稿改完重新提交；任一来源订单已月结则不能撤销。

**Q：验收后客户真退了货怎么办？**
走**退货单**（单据管理 → 退货单）：选原验收单，退货数量上限=实收−累计已退，单价锁定原验收价，提交后质检（可再售/不可再售）。**不要**为退货去撤销验收。

**Q：调价周到了，改哪里？**
「基础信息 → 商品报价」找到该客户报价单，批量调整明细价格并生效。

**Q：误删了客户商品怎么办？**
重新在「客户商品」里指派回该 SKU 即可；已生成的历史订单不受影响。
