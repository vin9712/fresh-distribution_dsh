## 使用

在打印模板管理中可找到 **金鸿楼总单**、**金兴楼总单**、**丽宫总单**、**大长江总单**。从客户日总表的“总单打印”入口进入，系统会自动选择客户专用模板。

## 大长江源样张的公式适配与班次改造（本次含代码改动）

### A. 源样张公式适配（静态样板）

源样张用了三种表格软件公式，原导入器只认其中一种，实测原样导入会**四个数量列全空**、合计行为 0、页面顶部出现公式错误条。已扩展 `JimuSampleImporter`（`lin-distribution`），并补单测（`JimuSampleImporterTest` 3→5 例）：

| 源样张写法 | 处理 | 原因 |
|---|---|---|
| `=IF(#{d.f}==0,'',color(#{d.f},'#c','#bg'))` | 降为纯绑定 `#{d.f}` | 引擎 `color()` 对空值输出字面量 `null`，且 `color()` 必须是最外层调用（用 IF/三元包裹会静默失败）——留白与逐行取色无法共存，以留白为准 |
| `=color(#{a}+#{b}+#{c}+#{d},'#c','#bg')` | 舍弃取色，合计预计算为 `sum1` 字段 | 同上；同时避开空值算术在报表引擎报错（原样渲染日志出现 `表达式解析失败 … color(+100`） |
| `=SUM(D4)` 列合计行 | 按该列在明细行绑定的字段在静态数据上预计算为字面量 | 单元格引用式 SUM 不被引擎求值（原样渲染为 0） |

代价与边界：**大长江静态样板数量列的逐行红/蓝字未保留**（品名、单位的取色保留，因为不会为空）；源样张的两级表头与供应商备注列保留。`=SUM` 列定位失败时写空串，不猜测。

该改动需 `mvn install` 后重启后端才生效（`lin-distribution` 以 jar 形式加载，devtools 不覆盖）。
