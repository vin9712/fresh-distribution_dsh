# 生鲜配送 ERP 交互优化方案（基于现有代码现状）

> 版本：v1.0  
> 日期：2026-08-22  
> 适用范围：RuoYi-Vue3 前端（Vue3 + Element Plus 2.13 + vxe-table 4.20）  
> 相关文档：`../02-redesign-r1/deepseek_ui_redesign.md`、`../02-redesign-r1/r1_redesign_progress.md`

---

## 1. 背景与目标

当前系统已具备良好的技术基础（QuickTable 范式、vxe-table 高级功能、JimuReport 打印），但在生鲜批发文员的高频操作场景下，仍存在若干体验断点。本方案聚焦于**录单、报价、验收、流程闭环**等关键环节，以“像 Excel 一样快、少切换、自动带出、异常高亮”为原则，补齐交互短板，提升文员工作效率。

---

## 2. 总体设计原则

- **键盘优先**：高频操作支持快捷键，双手不离键盘完成录单。
- **表格化录入**：充分利用 vxe-table 的行内编辑、键盘导航、批量粘贴、拖拽填充等能力。
- **自动带出**：商品、价格、单位、库存等信息自动填充，减少手工输入。
- **异常可视化**：库存不足、价格异常、验收差异等用颜色/图标提示，不打断操作流。
- **少弹窗，多用抽屉/浮层**：保持上下文，避免页面跳转。
- **容错与留痕**：草稿自动保存，关键操作记录日志。

## 3. 核心页面改造方案

### 3.1 销售订单详情页（`order/sale/detail.vue`，录单核心）

当前问题：无草稿保存，无常用商品面板，商品下拉匹配缺少别名高亮。

#### 3.1.1 草稿自动保存

**交互表现**：

- 订单表单右上角显示轻量状态提示：`未保存` → `草稿保存中...` → `已于 HH:mm:ss 自动保存`
- 页面刷新或意外关闭后，下次进入订单详情页或订单列表时，顶部弹出常驻提示条：  
  `检测到未完成的订单草稿 [客户名称]（保存于 HH:mm），点击恢复`
- 草稿仅保留当天 24 小时，过期自动失效。

**实现建议**：

- 使用 Pinia store + `localStorage`，每 30 秒或关键数据变更后 5 秒自动保存。
- 恢复时校验草稿时间与客户是否存在。

#### 3.1.2 常用商品面板

右侧 8 栏区域增加 `el-tabs`，包含两个 Tab：`常用` 和 `最近`。

- **常用 Tab**：根据当前选中的“送货单位”，拉取近 30 天下单频率最高的 15~20 个 SKU。
- **交互**：点击常用商品卡片，自动添加到左侧 vxe-table 末尾（或光标所在行下方），光标自动跳至该行“数量”列，直接输入数量后回车继续。
- **效果**：文员录入高频商品只需“点一下 → 输数量 → 回车”，无需搜索。

#### 3.1.3 商品搜索下拉优化（`vxe-pulldown`）

- 在下拉面板中，对匹配的关键词进行**高亮**（如输入“青”，列表中的“青”字标红）。
- 若命中来源为“客户别名”或“临时商品”，在商品名称后追加标签：  
  `上海青 [别名]` 或 `鲜切土豆 [临时]`
- 避免因别名歧义导致选错商品。

### 3.2 销售订单列表页（`order/sale/index.vue`）——补齐流程闭环

当前问题：`handleBuildPurchase` 和 `handleBuildDelivery` 为空函数，文员无法在列表页完成“生成采购单/送货单”操作。

**交互设计**：使用右侧抽屉（`el-drawer`），不跳页。

1. 文员勾选多个已确认订单，点击「生成采购单」或「生成送货单」。
2. 右侧滑出抽屉，内容分三步：
   - **第一步：汇总预览**  
     按品类分组展示商品（叶菜、根茎、肉禽等），方便采购/配送核对。
   - **第二步：填写信息**  
     采购单需选择供货商/采购员；送货单可调整配送日期。
   - **第三步：确认生成**  
     点击生成，显示成功提示，抽屉关闭。
3. 生成后，订单列表对应行显示小图标（如购物车/货车），悬浮显示已生成的采购单号或送货单号。

**注意**：抽屉内不阻塞当前列表，可随时关闭取消操作。

### 3.3 报价详情页（`product/quote/detail.vue`）——Excel 式批量调价

报价场景特点：商品数量多、价格变动频繁、需要批量修改。

#### 3.3.1 键盘流优化

- 设置 `keyboard-config`，使 Enter 键仅在“新报价”列**向下移动**，其他列按 Tab 移动。
- 文员录入新价后回车自动跳到下一行“新报价”单元格，连续录入。

#### 3.3.2 批量填充

- 支持选中多行后，右键菜单提供「向下填充」「向上填充」。
- 支持拖拽填充柄（vxe-table `mouse-config.extension` 已开启）。
- 在顶部工具栏增加「批量调价」按钮：输入涨幅百分比（如 5%），对选中行统一计算新报价。

#### 3.3.3 固定列与异常预警

- 商品名称列 `fixed: 'left'`，操作列 `fixed: 'right'`，保证横向滚动时关键信息可见。
- 当新报价偏离上次价或成本价超过阈值（如 >30% 或 < -10%）时，该单元格背景/边框变橙色，提示“涨幅异常”，文员确认后可继续。

#### 3.3.4 毛利率实时显示

- 表格中“毛利率%”列自动计算：`(新报价 - 成本价) / 新报价`，低于预设值（如 15%）时标红。

### 3.4 全局搜索 Ctrl+K（接通 QuickTable 预留事件）

当前 QuickTable 已 emit `global-search`，但无消费方。建议实现全局浮层搜索。

**交互设计**：

- 全屏居中的 `el-dialog` 或 `el-drawer`，类似 VS Code 的 `Ctrl+P`。
- 输入关键词，**分组展示**结果：
  - 客户：显示名称 + 别名
  - 商品：显示名称 + 编码 + 分类
  - 订单：显示单号 + 客户 + 日期
- 键盘上下选择，回车跳转（新建标签页打开对应详情）。
- 若当前正在录单且存在草稿，跳转前自动保存草稿，确保不丢失。

**实现提示**：监听 `window.keydown`，过滤输入法组合状态。

### 3.5 验收单录入弹窗（`order/acceptance/index.vue`）——大按钮/移动模式

> ⚠ **已废弃（2026-09-16）**：验收录入已收敛到订单明细页验收模式，验收单页降为台账（查看/打印）；
> **本系统无移动/扫码模式**，本节「移动模式」不再实施，仅作历史设计存档。

当前验收弹窗使用 el-table 编辑实收数量，在仓库现场可能使用手机/PDA 操作不便。

**交互优化**：在验收弹窗右上角增加「移动模式」切换按钮。

- 点击后，表格隐藏大部分列，仅显示“商品名称”和“实收数量”两个大输入框。
- 每屏只显示 2~3 个商品，上下滑动切换。
- 支持扫码枪连续扫码：扫到商品条码自动定位并累加实收数量。
- 移动模式下按钮加大、输入框调大，适应触屏和手套操作。

**注意**：移动模式仅改变布局，不影响数据保存逻辑。

### 3.6 一致性与权限修复（避免文员看不到按钮）

以下问题虽非纯交互，但直接影响文员使用，需一并处理：

#### 3.6.1 配送点页按钮权限缺失（`partner:customerDept:*`）

- 问题：`sys_menu` 未定义这些权限，非 admin 角色看不到配送点页的添加/编辑/删除/导出按钮。
- 解决方案：  
  临时方案：去掉按钮上的 `v-hasPermi`，改为所有用户可操作。  
  长期方案：补全 `sys_menu` 权限项。

#### 3.6.2 客户类型字典为空（`t_customer_type`）

- 问题：客户列表“客户类型”列渲染为空，影响文员判断。
- 解决方案：  
  在列表列中增加兜底渲染，若字典无值显示 `-` 或灰色斜杠；同时补全字典数据。

#### 3.6.3 报价详情路由权限拼写错误

- 问题：`router/index.js` 中 `permissions: ['partner:quote:add']`，实际权限为 `product:quote:add`，导致非 admin 用户无法注册路由。
- 解决方案：修正权限标识。

#### 3.6.4 旧权限残留（`price:point:*`）

- 问题：已被 `price:delivery-override:*` 取代，残留易混淆。
- 解决方案：清理 SQL 中相关菜单和权限数据。

## 4. 实施优先级

| 优先级 | 内容 | 理由 |
|--------|------|------|
| **P0** | 销售订单详情页：草稿自动保存、常用商品面板、下拉别名高亮 | 直接影响录单效率和数据安全 |
| **P1** | 销售订单列表页：生成采购单/送货单抽屉 | 补齐业务流程闭环，文员核心操作 |
| **P2** | 全局搜索 Ctrl+K | 提升跨模块查找效率，减少页面切换 |
| **P3** | 报价详情页：批量调价、异常预警、固定列 | 报价高频操作，优化批量处理体验 |
| **P4** | 验收单移动模式、权限与字典修复 | 现场操作便利性，系统基础数据准确性 |

## 5. 附录：关键技术注意点

- **vxe-table v4 菜单结构**：`menu-config` 为 `{ body: { options: [[...]] } }`，非 v3 直数组。
- **右键菜单图标**：`vxe-icon-wipe` 不存在，用 `vxe-icon-custom-column`。
- **树形表格**：不支持 `checkbox-config.range`，QuickTable 已自动降级。
- **列设置持久化**：需为每个 grid 设置唯一 `id`，且每列设置 `field`，才能正确保存至 `localStorage`。
- **输入法冲突**：全局快捷键监听时需判断 `compositionstart/end`，避免中文输入过程中误触。
- **性能**：订单明细、报价矩阵等大数据表格开启虚拟滚动（`scroll-y.gt=100`），保证流畅。
